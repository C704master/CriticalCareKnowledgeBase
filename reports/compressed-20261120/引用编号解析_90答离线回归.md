# ⑤ 引用编号解析的修复与回归

压缩病例正式实验入口现共用一套 E 编号解析。旧生成端把 `[E1,E2]` 读为空，旧评阅端读为 1、2；修复后两端都识别为 1、2。统计按每份答案中不同的有效编号计数，盲评隐藏同一套解析器识别到的标记。

## 格式测试

| 输入 | 应识别的编号 | 核查重点 |
|---|---|---|
| `[E1]` | 1 | 单号 |
| `[E1,E2]` | 1、2 | 原缺陷 |
| `[E1-E3]`、`[E1]—[E3]` | 1、2、3 | 括号内及跨括号范围 |
| `[E3,E1-E4,E6]` | 3、1、2、4、6 | 按首次出现去重，组合中的范围也展开 |
| `[E1-E3,E0]`，本题只有 E1、E2 | 1、2、3、0 | 后续校验能标出越界的 E3 和 E0 |
| `GCS E1VTM2，pH 7.0，[10-19查房]` | 无 | 临床评分、数值、病历日期照原样保留 |

15 组格式样例，以及逐行链接、越界检查均通过。逐行链接对跨行引用挂在闭括号所在行。沿用旧评阅器的范围展开上限 100；倒序或超过上限的范围只保留显式端点。生成结果文件仍按编号升序保存，评阅和展示按正文出现顺序读取。

## 旧答案回归

取冻结的 30 道原题，每题直答、静态查库、动态查库各一份。逐份核对归档模型响应、生成端编号、越界编号、统计表中的有效引用数，以及每条入模原文是否被正文点名。

| 组别 | 已核对答案 | 有效引用条次 | 越界编号条次 | 编号集合有差异的答案 |
|---|---:|---:|---:|---:|
| 直答 | 30 | 0 | 0 | 0 |
| 静态查库 | 30 | 119 | 0 | 0 |
| 动态查库 | 30 | 109 | 0 | 0 |
| 合计 | 90 | 228 | 0 | 0 |

这批旧答案中识别到的引用均为单号形式，组合引用的修复由独立格式样例验证。另在临时输出目录离线执行正式报告脚本，90/90 行的引用统计、30/30 份病例评阅包展开原文的编号及顺序与归档一致。新增模型调用为零。
