# 调用表怎样读

本表统计八篇报告所选实验目录的 310 个请求文件、323 条有状态记录的尝试。状态分布为 {'completed': 307, 'failed': 15, 'cancelled': 1}。范围覆盖 F28 定位四组、三道适用性开发题、F24 日期标题对照、F25 核源与成组审阅、速度对照、F22/F26 第十二批的 V1/V19/V20、F09/F12 原始配对和后续核源，以及 F28 过滤前后试验。各篇在证据入口列出本篇计数。第⑥篇的其他正式盲验批次、原三十例的所有其他请求不计入本表。

- reports 可以列多个篇号，request 是相对运行目录，attempt 是该次尝试。相同受控文件复用于多篇只计一次。基线或裁决被复用时，台账保留原调用；纯 Python 回放不会新增一行。
- system 对应 public-prompts 目录的 Markdown 文件。message_sequence 按实际发送顺序记录每条消息的角色、公开范围和内容 SHA-256。系统指令及经检查的非患者示例见对应文件；其他位置只登记指纹。完整病例、临床示例库及整份模型回复留在受控环境。
- request_sha256、response_sha256 是文件字节指纹，消息指纹按 UTF-8 原文计算。失败尝试没有完整响应时该栏为空。
- model_label_counts 仅统计模型 JSON 中识别出的有限枚举；空白包括自由文本答复，不能解释成零条提醒。程序动作、研究侧改判及适用范围见每篇结果与正文。elapsed_s 与 total_tokens 为原状态或响应中的实测字段；未记录留空。
