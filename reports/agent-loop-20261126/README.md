# Agent-loop 停查、日档字段选择与日期核验

本次归档汇总截至 11 月 26 日讨论的实验。正式实验循环调用 Qwen，并从本地只读日档摘录取证。研究侧预先给出应查的缺口和停止条件，保存首次结果，再按患者隔离复核。病例标记仅用于区分实验。

## ① 什么时候值得再查

同一道综合交班题给两种输入。A 已含关键记录，预期首轮停止。B 移除该记录，工具仍能取回，预期主动选择对应日档字段、获取新证据并用于答句。

首次两对独立题均失败。缺证据时，一例把术前小结当成具体术式已完成的依据，另一例从床旁体征直接判断灌注。两题随即转作开发。最终规划器把日期、文书性质和原句放在一起，按来源组织材料；查后可见读前暂答、查询目的及新增事实。

冻结 V15 后，两道旧题回归通过。在两名新患者的另拟综合交班题上，两组对照均通过。胸部外伤题缺少当天胸片时，模型查病程，取得双侧积液与早期影像的比较。心梗题缺当日心肌损伤指标时，模型查异常检验，取得实测值后更新趋势判断。两题在关键记录已给齐时均首轮停止。

独立四臂合计 10 次模型调用、11 次网络尝试、2 次日档查询，各臂耗时合计 105.88 秒。心梗题另加一组来源排列顺序配平对照，动作相同。终答仍有两处质量问题：心梗回答将数值下降误写为“回升”，胸外伤回答略去了两份记录对前一日指标的分歧。

## ② 缺的是执行记录还是床旁测量

同一题同时询问实际用药和指定时间的床旁读数。A 首轮已见执行，B 已见测量；两臂都保留来自监测、执行和检验的干扰条目。每个缺项须首轮选中正确字段，只查一次，取得新增目标并停止。C 为两项均已给齐的停止对照。

开发题 F07 的原规划器知道缺血糖，却先查异常检验，第二次才从床旁监测取回读数。最终答案虽正确，该臂仍计首次路由失败。修订规划提示词后，模型按记录如何产生来选字段。F07 两个方向都一次命中。

冻结后，两名新患者的四个缺项均首次命中，另一个资料齐全的条件直接停止。血糖题将床旁血糖和邻近时刻的动脉血气葡萄糖区分开；利尿剂题能在泵速和尿量之间选字段，也保留单点尿量不足以确认药效的判断。固定只读监测或只读执行，离线均只能覆盖四个缺项中的两个。

独立五臂合计 14 次模型调用、4 次本地读取，各臂耗时合计 64.21 秒。一份终答给未列单位的床旁读数补写了单位，另一份主动提到病例未给出的药效阈值。四类工具联合选择及完整生产日档检索仍待验证。

## 日期核验

F19 把计划日期与待核实事件日期分开，修订后四种回放均选择正确查询日。F28 的规则以查房记录日期解释“昨日”，在待核句和原文中定位到相符的数值组合后，输出冲突日期及原句供复核。F24 把执行日期、时刻、药名和剂量绑定到同一条来源，拦住了两晚给药的错配；对连续观察分别移除首日、中间日或末日材料，三种缺日情形都被拦截。F24 这次离线回归新增模型调用为零。

这些结果支持已定位句子的日期核验。完整日档和整篇答案能否自动找全错日、如何处理跨午夜以及同段跨截止点，仍待独立验收。
