每篇笔记在题录下记录发表载体、文章类型和以下指标，并附核查来源。

- 期刊论文记录期刊影响因子（JIF）、指标年份、JCR 学科和分区，有可核实的学科排名时一并记录。指标年份与论文发表年份分别标注。中科院分区如需记录，另列版本与来源。
- 会议论文记录会议全称、年份、主会或其他轨道、论文类型及正式论文集链接。采用 CCF 等级时标注目录版本和来源。会议论文的期刊 JIF 栏填“不适用”。
- 查不到官方指标时标“未核实”。另记研究设计，例如范围综述、回顾性病例研究或随机试验，方便判断文章能支持什么结论。
