# 重症知识库实验记录｜2026 年 11 月 1—19 日

这组实验围绕两个问题展开：检索能否把相关知识排到前面？这些知识进入模型后，能否让回答里的重要建议有据可查？前一个问题用检索排名验证，后一个问题用同病例对照和逐条来源核查验证。

**导师阅读入口**　[三份 Word 任务书与后续实验原件](originals/README.md) · [各批次结果、格式版本与台账覆盖清单](reports/06-record-coverage.md)

## 下一轮：30 个压缩病例（待开展）

旧 30 题已经生成 90 份答案，使用的是完整源病例。下一轮拟从压缩建档选取新病例，每例固定医生原题、患者摘要、连续三日日档和 Qwen v10，再比较无证据与知识增强两份答案。重点分别看患者日期与参数是否准确、重要建议是否能查回原文。[30 例配对测评计划](plans/archive30.md)
